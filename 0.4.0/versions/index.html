版本说明

文档入口对应实现适用范围
latest / 0.4.0release/v0.4（待发布）会话沙箱文件上传、列出、下载；ReadFile 图片视觉输入；重启后重新附着仍有效的沙箱。
0.3.10.3.1Cloud 会话绑定与显式刷新。自定义 Skill 使用空间中加载时可见的最新版本。
0.2.0v0.2.0请求级 Harness 配置与会话技能包。

控制面字段 HarnessVersion 是 Harness 配置资源的修订号。镜像版本由部署选择。参见创建 Harness 到对话。

0.4.0 待发布变更​

  • 沙箱图片读取。 ReadFile 将 PNG、JPEG、WebP、GIF 图片作为视觉内容返回，最大 5 MiB；扩展名与文件签名必须一致，图片不支持行范围。Harness Chat 和 OBO 的模型请求可消费视觉块，会话事件维持原有工具响应。
  • 会话文件 API。 新增上传、列出、下载操作。上传单文件最多 8 MiB，请求体最多 9 MiB；重复文件名返回 409，不覆盖已有文件。下载支持单段 Range。
  • 沙箱恢复。 Runtime 重启或切换实例后，按会话稳定标识重新查找仍有效的物理沙箱。沙箱 TTL 到期后旧文件仍会失效。

以上内容按 release/v0.4 的实现记录；正式发布版本以发布时的镜像为准。
