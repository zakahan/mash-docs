版本：0.4.0

VeADK Agent Loop

本手册对应0.4.0 待发布版本（release/v0.4 当前实现）。使用已发布的 0.3.1 或 0.2.0 镜像时，请在导航栏选择对应版本。

这个镜像为 AgentKit Runtime 提供三种组件。应用开发者根据调用方式选择入口；扩展运行时的开发者可以从各篇的执行过程进入实现。

组件在 AgentKit 中的职责使用入口
Harness App接收应用请求，组装本轮 Agent，执行模型与工具调用，返回文本或流式事件。实战教学
Managed Agents Worker执行托管会话的工作，消费固定的 Agent 配置，向托管服务回传执行事件。应用通过 Session 数据面读写消息。托管会话指南
Studio Harness为 Studio 提供独立的 Harness 服务。镜像代理通过请求头 X-AgentKit-Target: studio 将请求转给该服务。从 AgentKit Studio 使用

Harness 资源与运行时组件​

在 AgentKit 控制面，Harness 是一个有标识、有修订版本的配置资源，可描述模型、系统指令、工具与技能。调用方通过 Agentkit:Harness 管理接口 管理这些配置。Harness App 是镜像里的服务名称。从 0.3.1 起，调用方可用 Workspace、Harness 和 Cloud Environment 三个 ID 创建绑定会话；Harness App 读取控制面配置后，在当前实例保存快照供后续 SSE 消息使用。调用方可通过 refresh_snapshot 主动刷新，或通过 harness.system_prompt 等字段只覆盖本轮。完整调用链路

Managed Agents 在创建 Session 时通过 agent 引用 Harness，把选定的配置固定在会话中。

本站的版本选择器表示镜像版本；资源字段 HarnessVersion 表示某个 Harness 的配置修订号。版本说明

环境变量默认值说明
