高级配置与环境变量

在 AgentKit 的 Runtime 环境变量里设置下列参数。镜像启动器先按组件开关选择进程，Harness App 再组装默认 Harness Agent、会话服务和已启用的能力。调整部署配置后，让新的 Runtime 实例使用更新后的环境。对单轮消息生效的字段见调用配置。

Harness App 开关​

环境变量默认值说明
HARNESS_APP_ENABLEDtrue在 Runtime 中启动 Harness App。接受 true 或 false，忽略大小写和首尾空白。

共享镜像至少启用一个组件。普通 HTTP 请求路由到 Harness App；在代理运行且 Harness App 被关闭时，访问该目标返回 503。

配置工具控制面​

配置 AgentKit 沙箱、按 ID 引用 MCP 工具集或访问 Skill Space 时，Runtime 会向 Tool 控制面发起签名请求。签名中的服务名和实际连接的域名是两个参数。服务名用于请求签名，主机名决定请求发往哪里；修改其中一项不会自动保证另一项与目标入口匹配。

环境变量默认值说明
AGENTKIT_TOOL_SERVICE_CODEagentkitTool 控制面的签名服务名。
AGENTKIT_TOOL_HOST按客户端和地域推导Tool 控制面主机名。跨环境时显式指定。
REGION未设置MCP 查询在未指定工具地域时读取的回退地域。
AGENTKIT_TOOL_REGION依客户端与云环境工具所在地域；MCP 工具集查询可回退到 REGION，再取 cn-beijing。

默认入口​

在火山引擎环境中，不设置这组变量且地域使用默认的 cn-beijing 时，服务名为 agentkit，主机名为 agentkit.cn-beijing.volcengineapi.com。显式设置工具地域后，默认主机名按服务名和地域推导；自定义服务名不一定能直接作为域名前缀，因此自定义入口建议同时填写两项。

北京地域示例：

目标环境AGENTKIT_TOOL_SERVICE_CODEAGENTKIT_TOOL_HOST
生产agentkit（默认）agentkit.cn-beijing.volcengineapi.com

例如为北京地域的 MCP 工具集设置：

AGENTKIT_TOOL_REGION=cn-beijing
AGENTKIT_TOOL_SERVICE_CODE=agentkit
AGENTKIT_TOOL_HOST=agentkit.cn-beijing.volcengineapi.com
MCP_TOOLSET_ID=<本环境的工具集 ID>

自定义入口​

从目标服务的部署配置取得签名服务名、控制面主机名和地域，再设置：

AGENTKIT_TOOL_REGION=<目标地域>
AGENTKIT_TOOL_SERVICE_CODE=<目标入口要求的签名服务名>
AGENTKIT_TOOL_HOST=<目标控制面主机名>

AGENTKIT_TOOL_HOST 只填写主机名，不带 https:// 或请求路径；这里不需要修改操作系统的 hosts 文件。AGENTKIT_TOOL_SERVICE_CODE 必须与目标入口的签名配置一致，不能仅从域名猜测。更新 Runtime 环境变量后，让新实例加载配置，并使用同一目标环境下有权限访问的工具或技能资源验证调用。

  • 变量名只有一段 AGENTKIT_ 前缀。v0.2.0 的 Harness 工具调用读取 AGENTKIT_TOOL_SERVICE_CODE；写成 AGENTKIT_AGENTKIT_TOOL_SERVICE_CODE 时，此处仍按有效变量或默认值签名。
  • AGENTKIT_TOOL_HOST 填主机名。默认地址由各客户端根据服务名、地域和云环境拼接。使用自定义入口时，应按部署配置填写匹配的服务名和主机名。切换模型的 API 地址使用另一组模型参数。
  • AGENTKIT_TOOL_REGION 选工具所在地域。MCP 工具集查询依次取该变量、REGION、cn-beijing。Skill Space 和 AIO 沙箱在 BytePlus 环境有自己的地域和域名默认值。显式指定 region 和 host 可让多个客户端指向同一环境。
  • MCP 工具集查询使用 Runtime IAM 身份调用 GetMCPToolset，再连接返回的工具集地址。沙箱控制面支持 Runtime IAM 或临时云凭据。切换服务名和主机时，所引用的资源 ID 与调用身份也应属于对应环境。

会话存储与 PostgreSQL​

SHORT_TERM_MEMORY_TYPE 决定用户和会话对应的历史事件存在哪里。只设置数据库地址时，该选择项仍然使用默认值 local。

后端行为与配套配置
local默认进程内存。适合短期会话；其他副本有各自的会话空间。
sqlite存放在实例本地的 SQLite 文件，默认路径为 /tmp/veadk_local_database.db。文件生命周期取决于实例存储。
postgresql使用 DATABASE_POSTGRESQL_* 连接共享数据库。多个副本可访问同一组会话表。
mysql使用 DATABASE_MYSQL_HOST、DATABASE_MYSQL_USER、DATABASE_MYSQL_PASSWORD、DATABASE_MYSQL_DATABASE。自定义端口可写入 HOST 的 host:port。
环境变量默认值说明
SHORT_TERM_MEMORY_TYPElocal选择上表所列的会话后端。
DATABASE_MYSQL_HOST空MySQL 主机，自定义端口可写成 host:port。
DATABASE_MYSQL_USER空MySQL 用户名。
DATABASE_MYSQL_PASSWORD空MySQL 密码。
DATABASE_MYSQL_DATABASE空保存会话的 MySQL 数据库名。
DATABASE_POSTGRESQL_HOST空数据库主机，可含端口。
DATABASE_POSTGRESQL_PORT5432主机未指定端口时使用。
DATABASE_POSTGRESQL_USER空数据库用户名。
DATABASE_POSTGRESQL_PASSWORD空数据库连接密码。
DATABASE_POSTGRESQL_DATABASE空共享会话数据库名。
DATABASE_POSTGRESQL_SCHEMA空可选的会话表 schema。

为多个副本配置同一份会话历史​

SHORT_TERM_MEMORY_TYPE=postgresql
DATABASE_POSTGRESQL_HOST=db.example.com
DATABASE_POSTGRESQL_PORT=5432
DATABASE_POSTGRESQL_USER=harness_app
DATABASE_POSTGRESQL_PASSWORD=<由 Runtime 注入的数据库密码>
DATABASE_POSTGRESQL_DATABASE=agent_sessions
DATABASE_POSTGRESQL_SCHEMA=harness_app

连接参数填实际主机、用户名、密码和数据库名；端口默认 5432。如果主机值已经写成 host:port，其中的端口优先。DATABASE_POSTGRESQL_SCHEMA 是可选项，默认留空，使用数据库连接的默认 schema。显式指定时仅允许字母、数字、下划线，首字符为字母或下划线。后端执行 CREATE SCHEMA IF NOT EXISTS，并在事务中设置和验证 search_path。数据库账号需要相应的建表和 schema 权限。同一个应用的副本应指向相同数据库和 schema；切换后端或 schema 时，需要另行处理已有历史的迁移。

启动时 Harness App 使用 PostgreSQL advisory lock 协调 ADK 会话表初始化，等待锁默认最多 60 秒。实例连接不到指定的共享库或锁超时时，启动失败，便于在接收业务流量前发现配置问题。

连接池​

以下数值按每个服务进程配置，适用于 PostgreSQL 和 MySQL 会话后端。规划连接数时应考虑副本数。例如 4 个进程均使用默认值时，这些会话连接池允许的并发连接合计上限为 4 × (5 + 3) = 32，还需给初始化连接和其他业务预留容量。

环境变量默认值说明
HARNESS_SESSION_DB_POOL_SIZE5池内可保留的连接数。允许范围为 1–100。
HARNESS_SESSION_DB_MAX_OVERFLOW3池满后额外允许的连接数。允许范围为 0–100。
HARNESS_SESSION_DB_POOL_TIMEOUT_SECONDS10 秒等待可用连接的时限。允许范围为 1–120。
HARNESS_SESSION_DB_POOL_RECYCLE_SECONDS300 秒借出连接时检查的连接回收年龄。允许范围为 30–3600。

指定工具执行的沙箱​

ADK 选择沙箱 Tool 后提供 Execute、ReadFile、EditFile 和 WriteFile。首次实际执行沙箱工具时才创建沙箱。Tool ID 的读取顺序是本次请求的 harness.sandbox.tool_id、部署的 HARNESS_SANDBOX_TOOL_ID、部署的 AGENTKIT_TOOL_ID。

环境变量默认值说明
HARNESS_SANDBOX_TOOL_ID空选择部署使用的沙箱 Tool，本轮请求可覆盖。
AGENTKIT_TOOL_ID空部署未指定 Harness 沙箱 Tool 时的回退值。
HARNESS_SANDBOX_TOOL_ID_ALLOWLIST空逗号分隔的允许列表，用于校验传入的请求级 Tool ID。
VEADK_AIO_WORKSPACE/home/gem使用沙箱内已存在的绝对目录。
VEADK_AIO_SESSION_TTL_SECONDS28800 秒请求级 harness.sandbox.ttl 可覆盖，允许 60–86400 秒。
SANDBOX_API_KEY空可选，沙箱数据面需要时提供。
VEADK_AIO_STORE_URL本地 SQLite默认 SQLite 文件位于 ~/.veadk/aio/lifecycle.db。跨副本共享沙箱控制面限流状态时，填写共同的 postgresql+psycopg2://... 地址。

AIO 限流库与前述 ADK 会话数据库各自配置。沙箱绑定保存在服务进程内；共享 ADK 会话库可恢复对话历史，跨副本复用原沙箱还涉及会话粘性路由。同一对话变更沙箱 Tool 或 Skill Space 时需要新建会话。

运行身份需要哪些 IAM 权限​

先确定谁发起云 API 调用。例如应用向 Harness App 发送消息后，若 Agent 引用了 MCP_TOOLSET_ID，运行时会使用自己的身份调用 GetMCPToolset，随后连接返回的 MCP 地址。前一步需要给 Runtime 的执行角色授权，后一步使用工具服务要求的认证。直接填写 MCP_SERVERS 地址时可以省去工具集查询。

已启用的能力执行角色涉及的 Action触发时机
按 ID 连接 MCP 工具集agentkit:GetMCPToolset发现工具时查询服务地址和连接信息。
Skill Spaceagentkit:ListSkillsBySpaceId从空间选择技能或准备沙箱技能。只挂载已有技能的路径无需创建技能。
AIO 沙箱agentkit:CreateSession、agentkit:GetSession、agentkit:ListSessions创建沙箱会话、查询其状态及回查已有会话。这里的 Session 是工具沙箱资源。
沙箱内 Skill 下载（临时 URL 方案）agentkit:ListSkillsBySpaceId、agentkit:GenTempTosObjectDownloadUrl；空列表诊断分支可用 agentkit:GetSkillSpace沙箱加载器使用本次加载获得的临时身份查询、下载技能。实际下载授权取决于沙箱镜像的加载器。
A2A 注册中心搜索agentkit:SearchAgentCardsAgent 使用已配置的注册中心搜索工具时。直接调用已知 A2A 地址走该服务自身的认证。
网页搜索、APMPlusvolc_torchlight_api:WebSearch、apmplus_server:GetAppKey分别对应使用云端网页搜索和通过云 API 获取观测服务 AppKey。按实际启用项选择。
TOS 产物桶级 tos:HeadBucket、tos:ListBucket；对象级 tos:GetObject、tos:PutObject、tos:DeleteObject初始化检查桶、列出和读写产物；清理或删除对象的路径需要删除权限。定时任务使用单独的存储前缀，应对相应桶和前缀授权。

平台集成与资源预置权限​

已有的平台角色策略可能还覆盖下列操作。配置角色前，按实际 SDK、认证方式与资源准备流程确认调用方；把相应语句放到执行该操作的角色上。

操作范围策略中常见的 Action角色与适用条件
方舟模型密钥与端点管理ark:GetApiKey、ark:ListApiKeys、ark:GetRawApiKey、ark:GetEndpoint、ark:DescribeModelEndpoints按所用模型凭据解析器或端点管理流程授权，直接注入模型 API Key 时调用模型使用该凭据。Worker 按 Key Name 取密钥的链路见 Worker 配置。
平台资源发现与管理agentkit:GetA2aAgent、agentkit:ListA2aSpaces、agentkit:GetTool、agentkit:InvokeTool、agentkit:GetSkillInfo、agentkit:CreateSkill对应资源查询、调用或创建方。部署阶段创建 Skill 的身份和运行阶段读取 Skill 的身份可各自授权。
记忆、身份和知识库集成mem0:Get*、mem0:List*、mem0:Describe*；id:Get*、id:List*、id:Check*；ml_platform:GetCollectionInfo、ml_platform:SearchKnowledge、ml_platform:AddDoc根据选用的后端确定读写范围。只检索已有知识库时应单独核对查询权限；写入文档的流程再考虑 AddDoc。通配项属于平台策略示例，实际授权可按调用收窄。
准备 TOS 桶与浏览器访问tos:CreateBucket、tos:PutBucketCORS由建桶和配置跨域规则的预置流程使用；Harness App 使用已经准备好的产物桶。
