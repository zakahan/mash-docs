Harness App 调用接口

本页适用于镜像 0.2.0 的 Runtime HTTP 入口，覆盖 Harness Agent 的会话、执行和产物查询。请求路径相对于已授权的 Runtime 地址。示例使用应用名 harness_agent、用户 reader-1 和会话 report-1。认证主体和路径中的用户需满足该入口的身份要求。

操作选择接口
打开会话列表、恢复聊天历史ListSessions、GetSession
开始对话、修改业务状态、清理记录CreateSession、CreateSessionWithId、UpdateSession、DeleteSession
完整事件数组、实时事件流RunAgent、RunAgentSSE
简化输入、取得兼容的文本结果Invoke（SSE）、HarnessInvoke（JSON）
展示会话生成的文件ListHarnessArtifacts

会话标识与响应约定​

X-Session-Id 是 Runtime 返回的可选路由亲和标识；收到后原样回传。同一业务对话仍需保存创建响应正文中的 id，用作路径或请求体的会话标识。JSON 请求发送 Content-Type: application/json；流式调用可声明 Accept: text/event-stream。示例只列与各操作相关的字段，认证头见各接口表。

GET /apps/{app_name}/users/{user_id}/sessions​

查询会话列表 · ListSessions

查询指定用户在 Harness App 下的全部会话，用于展示会话列表。

请求参数

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>；具体 token 类型由 Runtime 的认证模式决定。
X-Session-Id string · Header · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
app_name string · Path · 必填
应为 harness_agent。
user_id string · Path · 必填
会话所属用户标识。

调用示例

GET /apps/harness_agent/users/reader-1/sessions

响应字段

X-Session-Id string · Header · 可能省略
Runtime 分配的会话亲和标识；后续请求应原样回传。
[] Session[] · Body · 必返会话数组；没有会话时返回空数组。
id string · Body · 必返
会话标识。
appName string · Body · 必返
应用名。
userId string · Body · 必返
会话所属用户标识。
status string · Body · 必返
Runtime 维护的真实会话运行状态，不从 events 推断。枚举：idle（空闲或正常完成）、running（正在执行）、waiting（等待认证、确认、异步结果或未闭合工具调用）、error（执行失败）。
title string · Body · 必返
会话标题。首次收到非空用户文本时，Runtime 在本地取第一句话生成，最长 40 个字符，且不调用模型（额外模型 Token 消耗为 0）；后续消息不自动覆盖。尚未生成标题的会话返回 新会话。
state object · Body · 必返会话状态；可为空对象。
{key} any · Body · 可能省略
业务自定义状态项。
events Event[] · Body · 必返
按发生顺序保存的会话事件；可为空数组。
lastUpdateTime number · Body · 必返
最近更新时间，Unix 秒时间戳；未发生更新时可为 0。

空列表返回 HTTP 200 和 []。已有会话时返回下文 GetSession 对象组成的数组。恢复历史请读取会话详情；列表返回的事件数量取决于会话后端。

POST /apps/{app_name}/users/{user_id}/sessions​

创建会话 · CreateSession

创建会话，用于在未预先指定会话 ID 时开始一次新对话。

请求参数

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>；具体 token 类型由 Runtime 的认证模式决定。
X-Session-Id string · Header · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
app_name string · Path · 必填
应为 harness_agent。
user_id string · Path · 必填
会话所属用户标识。
id string 或 null · Body · 可选
显式会话 ID，非空时优先于 sessionId。
sessionId string or null · Body · 可选
指定会话 ID；省略或为 null 时由服务端生成。
state object or null · Body · 可选初始会话状态。
{key} any · Body · 可选
业务自定义状态项。
events Event[] or null · Body · 可选
初始化到会话中的事件列表。
skills SkillResource[] · Body · 可选Session 级 Skill 快照；创建时保存到 Session，后续 POST /run_sse 使用同一 sessionId 时会自动恢复并加载。当前支持外部公开 Skill zip 包。
type string · Body · 必填
Skill 类型；外部公开 Skill 包固定为 external_skill_package。
source string · Body · 可选
Skill 来源；外部公开 Skill 包使用 public_url。省略时按 public_url 处理。
url string · Body · 必填
外部公开 Skill zip 下载链接，必须是 HTTPS URL；不要求 URL path 以 .zip 结尾，Runtime 按响应内容校验 zip 包。

调用示例

POST /apps/harness_agent/users/reader-1/sessions
Content-Type: application/json

{"sessionId":"report-1","state":{"report":"Q1"}}

响应字段

X-Session-Id string · Header · 可能省略
Runtime 分配的会话亲和标识；后续请求应原样回传。
id string · Body · 必返
会话标识。
appName string · Body · 必返
应用名。
userId string · Body · 必返
会话所属用户标识。
state object · Body · 必返会话状态；可为空对象。
{key} any · Body · 可能省略
业务自定义状态项。
events Event[] · Body · 必返
会话事件；可为空数组。
lastUpdateTime number · Body · 必返
最近更新时间，Unix 秒时间戳。

响应示例：

{
  "id": "report-1",
  "appName": "harness_agent",
  "userId": "reader-1",
  "state": {
    "report": "Q1"
  },
  "events": [],
  "lastUpdateTime": 1794800000
}

返回创建的会话，保存 id。使用 {} 可由服务分配 ID。镜像的集合创建入口也接受正文 id，同时提供时优先使用非空的 id。

POST /apps/{app_name}/users/{user_id}/sessions/{session_id}​

使用指定 ID 创建会话 · CreateSessionWithId

调用方可以使用业务系统中的标识作为会话 ID，后续通过同一 ID 读取会话或继续对话。

请求参数

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>；具体 token 类型由 Runtime 的认证模式决定。
X-Session-Id string · Header · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
app_name string · Path · 必填
应为 harness_agent。
user_id string · Path · 必填
会话所属用户标识。
session_id string · Path · 必填
要创建的会话标识。
请求体 object 或 null · Body · 可选
直接提供初始状态的键值对象。

调用示例

POST /apps/harness_agent/users/reader-1/sessions/report-1
Content-Type: application/json

{"report":"Q1"}

响应字段

X-Session-Id string · Header · 可能省略
Runtime 分配的会话亲和标识；后续请求应原样回传。
id string · Body · 必返
与请求的 session_id 相同。
appName string · Body · 必返
应用名。
userId string · Body · 必返
会话所属用户标识。
state object · Body · 必返会话状态；可为空对象。
{key} any · Body · 可能省略
业务自定义状态项。
events Event[] · Body · 必返
会话事件；可为空数组。
lastUpdateTime number · Body · 必返
最近更新时间，Unix 秒时间戳。

返回会话对象；重复创建同一 ID 可返回 409。该路由随 ADK SDK 提供，其处理器直接将 JSON 对象作为初始 state。需要一并写入历史事件或 Skill 快照时，使用上一节的集合创建入口。

会话标识。

GET /apps/harness_agent/users/reader-1/sessions/report-1

X-Session-Id string · Header · 可能省略

会话标识。

Runtime 维护的真实会话运行状态，不从 events 推断。枚举：idle（空闲或正常完成）、running（正在执行）、waiting（等待认证、确认、异步结果或未闭合工具调用）、error（执行失败）。

PATCH /apps/{app_name}/users/{user_id}/sessions/{session_id}​

更新会话状态 · UpdateSession

合并更新会话状态，用于不执行 Agent 的状态写入。

请求参数

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>；具体 token 类型由 Runtime 的认证模式决定。
X-Session-Id string · Header · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
app_name string · Path · 必填
应为 harness_agent。
user_id string · Path · 必填
会话所属用户标识。
session_id string · Path · 必填
会话标识。
stateDelta object · Body · 必填要合并到当前会话状态的字段集合。
{key} any · Body · 可选
要新增或覆盖的状态项。

调用示例

PATCH /apps/harness_agent/users/reader-1/sessions/report-1
Content-Type: application/json

{"stateDelta":{"report":"Q2"}}

响应字段

id string · Body · 必返
会话标识。
appName string · Body · 必返
应用名。
userId string · Body · 必返
会话所属用户标识。
state object · Body · 必返更新后的完整会话状态。
{key} any · Body · 可能省略
业务自定义状态项。
events Event[] · Body · 必返
会话事件；可为空数组。
lastUpdateTime number · Body · 必返
最近更新时间，Unix 秒时间戳。

响应包含更新后的 state。已有的其他顶层键保留；服务追加状态变更事件。会话不存在返回 404。

POST /run​

运行对话 · RunAgent

在已创建的会话中执行一次 Agent 并在执行完成后返回事件数组，适用于非流式调用。

请求参数

认证凭证，格式为 Bearer <token>；身份模式下 userId 的有效值由认证主体决定。
X-Session-Id string · Header · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
appName string or null · Body · 可选

userId string · Body · 必填
用户标识；身份模式下服务端使用认证主体覆盖该值。
sessionId string · Body · 必填
已创建的会话标识。
newMessage Content or null · Body · 可选本轮输入消息。
role string or null · Body · 可选
消息角色，调用方消息通常为 user。
parts Part[] or null · Body · 可选消息分片。
text string or null · Body · 可选
文本内容。
inlineData Blob or null · Body · 可选
内联二进制内容，包含 MIME 类型和 Base64 数据。
fileData FileData or null · Body · 可选
URI 文件内容。
functionCall FunctionCall or null · Body · 可选
函数调用。
functionResponse FunctionResponse or null · Body · 可选
函数调用结果。
executableCode ExecutableCode or null · Body · 可选
可执行代码。
codeExecutionResult CodeExecutionResult or null · Body · 可选
代码执行结果。
thought boolean or null · Body · 可选
是否为思考内容。
thoughtSignature string or null · Body · 可选
Base64 编码的思考签名。
videoMetadata VideoMetadata or null · Body · 可选
视频元数据。
mediaResolution PartMediaResolution or null · Body · 可选
媒体分辨率配置。
toolCall ToolCall or null · Body · 可选
服务端工具调用。
toolResponse ToolResponse or null · Body · 可选
服务端工具调用结果。
partMetadata object or null · Body · 可选
分片自定义元数据。
audioTranscription Transcription or null · Body · 可选
音频转写内容。
streaming boolean · Body · 可选
是否要求模型流式生成；默认 false。
stateDelta object or null · Body · 可选
本轮执行前合并到 Session 的状态增量。
functionCallEventId string or null · Body · 可选
续接函数调用时对应的事件 ID。
invocationId string or null · Body · 可选
调用标识；省略时由服务端生成。
customMetadata object or null · Body · 可选
调用方自定义元数据。

mcp_toolset_id string · 可选
MCP ToolSet ID，只能选一个，而且是本账号下的。

resources · array · 可选。结构见同页的顶层资源字段。

应为 harness_agent；兼容输入 app_name。

AgentKit MemoryStore ID，仅作为已冻结快照的来源标识；Runtime 不使用该字段回查 AgentKit。
context_id string · 必填
OpenViking Context ID，必须以 ov- 开头。
path string or null · 可选
OpenViking 路径类型；长期记忆只允许 memories，省略时按 memories 处理。
store_path string or null · 可选
MemoryStore 在 OpenViking memories 下的目录段；由 AgentKit 创建 Session 时冻结。
root_uri string or null · 可选
MemoryStore 根 URI，例如 viking://.../memories/{store_path}/；用于运行时定位和审计。
peer object or null · 可选
OpenViking 读写的 peer 配置；省略时使用当前用户派生 peer。
peer.mode current_user or explicit · 可选
peer 解析模式；current_user 表示 Runtime 按 userId 派生，explicit 表示使用 peer_id。
peer.peer_id string or null · 可选
mode=explicit 时必填；必须是安全路径段。
credential_ref object · 必填
OpenViking 凭证引用；只允许 Identity API key provider 引用，不允许明文 api_key、token、cookie 或 secret。
credential_ref.type string · 必填
固定为 identity_api_key_provider。
credential_ref.Name string · 必填
Identity API key provider 名称，例如 openviking-user-key。
credential_ref.PoolName string · 必填
Identity API key provider 池名称，例如 default。
access read_only or read_write · 可选
访问模式；默认 read_only，只召回不自动保存；read_write 会启用 write_memory 和会话后保存。
external_skill_package 资源条目
type string · 必填
资源类型；外部公开 Skill 包固定为 external_skill_package。
source string · 可选
外部公开 Skill 包使用 public_url。省略时按 public_url 处理。
url string · 必填
外部公开 Skill zip 下载链接。Runtime 下载并校验 zip 后读取 SKILL.md，将 Skill 的 name 和 description 注入 system prompt，并挂载为 ADK SkillToolset。

请求示例

{
  "app_name": "harness_agent",
  "user_id": "reader-1",
  "session_id": "report-1",
  "new_message": {
    "role": "user",
    "parts": [{"text": "总结本周报告。"}]
  },
  "streaming": true,
  "harness": {
    "system_prompt": "用三条要点回复。",
    "max_llm_calls": 3
  }
}

请求头​

Authorization string · 必填
认证凭证，格式为 Bearer <token>；身份模式下 userId 的有效值由认证主体决定。
X-Session-Id string · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
X-Model-API-Key string · 可选
本次请求使用的模型 API 密钥，值为原始密钥，不包含 Bearer 等认证方案前缀；同时提供时优先于 harness.model_api_key。

响应与错误​

成功建连后以 text/event-stream 逐帧发送 ADK Event。请求级适配器使用 Cache-Control: no-cache。以下仅展示文本相关字段：

data: {"partial":true,"content":{"parts":[{"text":"甲"}]}}

data: {"partial":false,"content":{"parts":[{"text":"甲乙"}]}}

兼容处理器在建连前发现参数错误时返回 HTTP 422；建连后执行失败可返回 data: {"error":"..."} 并结束流。客户端应读完整消息结算预览文本。流式事件消费

POST /invoke​

简化流式调用 · Invoke

使用简化请求执行默认 Harness 并流式返回事件，适用于不需要显式管理应用名和 Session 创建过程的调用方。

请求参数

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>；身份模式下用户标识取认证主体。
user_id string · Header · 可选
legacy 模式的用户标识；默认 agentkit_user；身份模式忽略该值。
session_id string · Header · 可选
会话标识；默认空字符串；会话不存在时自动创建。
prompt string · Body · 可选
用户输入。若缺失，则将整个 JSON Body 序列化为输入；非 JSON Body 按 UTF-8 文本处理。
{key} any · Body · 可选
prompt 缺失时参与序列化的任意 JSON 字段。

调用示例

POST /invoke
Content-Type: application/json
session_id: report-1

{"prompt":"总结报告。"}

响应字段

Content-Type string · Header · 必返
text/event-stream。
Cache-Control string · Header · 必返
no-cache。
data Event JSON · Body · 可能省略普通 SSE 帧；Event 字段与 POST RunAgent 的响应元素相同。
error string · Body · 可能省略
建连后执行失败时返回的错误帧；身份模式固定为 agent execution failed。

返回 SSE。此入口使用 Header 中的 session_id；会话不存在时可自动创建。

POST /harness/invoke​

使用配置覆盖调用 · HarnessInvoke

执行一次带可选 Harness 覆盖的非流式调用，适用于 legacy KeyAuth Runtime 的兼容调用。

请求参数

Authorization string · Header · 必填
Runtime KeyAuth 或自定义 JWT 凭证；身份模式不注册本接口。
prompt string · Body · 必填
用户输入。
harness_name string · Body · 必填
返回结果中使用的 Harness 名称。
harness object or null · Body · 可选
本次调用覆盖；字段与 POST RunAgentSSE 的 harness 完全相同。
run_agent_request object · Body · 必填会话与调用限制。
user_id string · Body · 必填
用户标识。
session_id string · Body · 必填
会话标识。
max_llm_calls int or null · Body · 可选
最大模型调用次数，最小值为 1。

调用示例

POST /harness/invoke
Content-Type: application/json

{"harness_name":"report","prompt":"回复 OK","run_agent_request":{"user_id":"reader-1","session_id":"report-1"}}

响应字段

harness_name string · Body · 必返
请求中的 Harness 名称。
overwrite boolean · Body · 必返
请求是否提供了 harness 覆盖。
output string · Body · 必返
Agent 最终输出；执行失败时为空字符串。
error string or null · Body · 必返
执行错误；成功时为 null。
artifacts Artifact[] · Body · 必返本次调用产生的产物；无产物时为空数组。
name string · Body · 可能省略
产物名称。
url string · Body · 可能省略
产物访问地址。
mime_type string or null · Body · 可能省略
MIME 类型。
size int or null · Body · 可能省略
字节数。
source string · Body · 可能省略
产物来源。
version int, string or null · Body · 可能省略
产物版本。

响应示例：

{
  "harness_name": "report",
  "overwrite": false,
  "output": "OK",
  "error": null,
  "artifacts": []
}

仅在未启用且未强制共享身份时注册。即使 HTTP 为 200，调用方也应检查正文 error。

GET /harness/artifacts​

查询会话产物 · ListHarnessArtifacts

查询指定 Session 产生的最新产物，用于结构化客户端展示或下载产物。

请求参数

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>。
session_id string · Query · 必填
Session 标识。
user_id string · Query · 可选
legacy 模式下默认 default；身份模式下由认证主体覆盖。
app_name string · Query · 可选
默认 harness_agent。
invocation_id string · Query · 可选
仅返回指定 Invocation 的产物。
since number · Query · 可选
仅返回该 Unix 秒时间戳之后创建的产物。

调用示例

GET /harness/artifacts?user_id=reader-1&session_id=report-1

响应字段

artifacts Artifact[] · Body · 必返最新产物数组；产物能力未启用或没有匹配项时为空数组，最多返回 50 项。
name string · Body · 可能省略
产物名称。
url string · Body · 可能省略
产物访问地址。
mime_type string or null · Body · 可能省略
MIME 类型。
size int or null · Body · 可能省略
字节数。
source string · Body · 可能省略
产物来源。
version int, string or null · Body · 可能省略
产物版本。

无记录或产物服务关闭时返回 {"artifacts":[]}。服务启用时缺少 session_id 或 since 格式无效返回 400。

本页字段与示例适用于 0.2.0 镜像，版本适用范围见版本说明。
