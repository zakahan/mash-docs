Managed Agents API：Session 与事件

本页描述与 Runtime 配套的 Session 接口契约。目标环境的接口可用性取决于控制面版本。

接口的请求参数、嵌套字段和响应示例均在本页列出。认证方式见调用约定。

本页成功响应直接返回业务对象，不包含 ResponseMetadata / Result 包装；具体结构见各接口说明。

接口分面功能
CreateAgentSession（REST）数据面创建会话
GetAgentSession（REST）数据面查询会话
ListAgentSessions（REST）数据面列出 AgentSessions
UpdateAgentSession（REST）数据面更新会话
ArchiveAgentSession（REST）数据面归档会话
DeleteAgentSession（REST）数据面删除会话
SendSessionEvents（REST）数据面发送会话事件
ListSessionEvents（REST）数据面列出会话事件
SessionEventsStream（REST）数据面订阅会话事件
ListSessionResources（REST）数据面列出会话资源

本页覆盖 Session 生命周期、事件写入、历史查询和 SSE 订阅。本页接口均为 REST，成功响应直接返回业务对象。创建、查询、更新、归档及列表元素复用本页的 Session 对象。

配置支持边界​

budget、resources、vault_ids 可以随创建请求保存。resources 中的 TOS 声明不再进入挂载执行链（能力已移除，只保存并返回）；type=memory_store 支持挂载 AgentKit 已管理的 MemoryStore，并展开为运行时 OpenViking 记忆快照；type=openviking_context, usage=memory 兼容绑定用户已提前准备好的 OpenViking Context 作为记忆资源；记忆资源默认 read_only，显式 read_write 才允许 agent-loop 会话结束后写入 OpenViking。预算、Vault 和其他资源类型的执行边界如下，保存声明不等于相应能力已启用。

字段创建与查询当前执行边界
budget / Budget对象或 null；省略/null 返回 null。不验证 Claude 金额结构、不按金额或 token 限额中止、不实现预算耗尽恢复；更新接口不接受 budget。
resources / ResourcesJSON 数组；省略/null 返回 []；ListSessionResources 返回此数组。TOS 声明 {type:"tos",tos_bucket,tos_key} 仅保存；MemoryStore 输入为 {type:"memory_store",memory_store_id} 或 {Type:"memory_store",MemoryStoreId}，可选 access/read_write 或 Access/read_write；创建时按账号和 Workspace 校验 active Store 后展开为 type=openviking_context、usage=memory、source=memory_store、memory_store_id、context_id、path=memories、store_path、root_uri、peer、credential_ref、access。直接 OpenViking 记忆绑定创建时归一为 context_id、path=memories、peer、credential_ref、access；省略 access 默认 read_only，仅允许 read_only 或 read_write。credential_ref 是 Identity provider 引用，不是 OpenViking API Key。TOS 存储挂载能力已移除：{type:"tos",tos_bucket,tos_key} 不再解析或挂载到 /mnt/session/storage/ 或 /mnt/session/outputs/，也不再冻结输入输出目标，仅按普通声明保存并返回。AgentKit 不保存真实密钥、不代理 Memory CRUD；MemoryStore 与 OpenViking Context 均在 Session 创建时固定运行时快照，agent-loop 根据快照用 credential_ref 换取真实 key 后挂载 load_memory。read_only 只召回不自动写入；read_write 会启用 agent-loop 的会话后保存，由 OpenViking 负责抽取和持久化。归档或删除的 MemoryStore 不允许新 Session 挂载。其他资源类型仍只保存并返回。
vault_ids / VaultIds字符串数组；省略/null 返回 []。不根据这些 ID 查询凭据或挂载 Vault；更新时非 null 值（包括 []）返回 400。

模型和 MCP 身份使用已实现的 Session 模型身份与 credential_keys 流程；这些身份引用不能由 vault_ids 替代。Claude 的预算和Vault属于官方服务的执行能力，本服务没有实现相同能力。

状态、固定版本与更新​

status含义
idle等待输入或工具确认；空会话创建后为 idle。
running会话工作正在执行。
rescheduling遇到可重试问题，等待重新调度。
terminated已结束或归档。

requires_action 是事件 stop_reason，不是 Session.status。用本轮的 session.status_idle 与 stop_reason 判断是否等待输入，不能将 HTTP 200、工具 Ready 或 SSE 断开当成本轮完成。

创建后固定环境、Runtime、Harness 快照和 Skill 版本。Harness 后续更新不会改变已有会话；Session 更新仅修改 title、metadata、agent.tools 和 agent.mcp_servers，tools/MCP 数组整体替换，[] 清空。模型、system、skills、环境、模板、工作池和方舟 API Key Name 不可更新。当前更新未校验 idle 状态；为避免运行中配置变化，调用方应先等待 idle 再改工具定义。Claude 官方 Session 更新要求 idle，该状态限制尚未由本服务强制执行。

归档保留 Session/Event 和首次 archived_at，停止活动 Work，没有取消归档。Delete 是单个会话的异步清理：受理成功不表示全部物理实例已清理；确认 Get 返回 404。

创建时，agent 字符串引用当前版本；{"type":"agent","id":"agent_example","version":1} 查询同账号、未归档 Harness 的历史版本。agent_with_overrides 在基础版本上整体替换提供的 model/system/tools/mcp_servers/skills，省略字段继承；null 清空可清空字段，模型不可清空。模型覆盖不继承基础模型的 effort、speed 或 inference_geo；未提供的 effort/地域返回 null，speed 默认 standard。工具清空要求有效 skills 为空，MCP 服务清空要求移除引用该服务的 mcp_toolset。覆盖不会更新 Harness，也不能覆盖其 AgentLoop；生成的会话快照和技能版本在创建后固定。已有完整内联配置继续作为本地扩展支持。官方行为依据见Session 创建与覆盖。

分页与筛选​

接口请求分页返回字段顺序与边界
Session 列表limit 默认 100，0 也按 100；有效范围 1～100。page 原样使用上一页游标。next_page/prev_page；无后续/前页时为 null。按创建时间排序，默认 desc；支持 asc。默认隐藏归档对象。
Event 列表limit 默认 100，0 也按 100；有效范围 1～1000。page 使用响应给出的十进制序号字符串。has_more/next_page。默认 sequence asc；desc 从游标之前向前读取。after_sequence 始终为排除式下界。
Session 资源列表无分页入参。data、has_more=false。仅返回已保存 resources 声明。

Session 的 page 与 Event 的序号、Environment 的 page 和其他列表接口的游标不能互换。翻页时保持 order 和过滤条件一致。当前 Session 游标包含时间、ID 和前后方向，不校验 order 或过滤条件是否改变；调用方改变排序可能重复或遗漏。Claude 官方Session 分页会校验游标与 order 和时间范围，本服务尚未实现该验证。

时间筛选使用本页字段表所列 created_at_gt/gte/lt/lte，当前不读取 Claude 的 created_at[gt/gte/lt/lte] 写法。Event 当前按 sequence 排序，不支持 Claude Event 接口按 processed_at 筛选/排序。processed_at 当前在事件受理时写入，不表示模型处理完成；不要提交未声明的查询参数。

事件写入、SSE 与恢复​

同一事件 ID 与同一内容可以重放；内容不同返回 409。未提供 ID 时服务生成 ID，网络失败后用新 ID 重试可能产生重复事件。Event 与后继 Work 同事务；503 时写入可能已经提交，重试必须保持原 ID 和正文。

SSE 持久化帧的 id 是十进制 sequence，data 是完整事件；只有持久化事件推进恢复游标；预览 event_start/event_delta 不保存、没有 id，断线不能重放。

正的 after_sequence 优先于 Last-Event-ID；显式 after_sequence=0 也会回退 Last-Event-ID。若希望从起点重读，应同时省略/清空 Last-Event-ID。没有正数或有效头时从 0 开始，返回已有历史后继续订阅。客户端保存最后已处理持久化帧的 id，断线后重连并按事件 ID 去重。

服务在等待新事件时每 15 秒发送注释心跳；设置 5 分钟定时器，到期后在等待阶段关闭连接。持续回放积压事件或写入阻塞时不保证恰好 5 分钟结束。连接关闭不改变会话状态，客户端应自动重连。200 之后发生的订阅错误以 error 帧返回，区别于会话的 session.error 业务事件。

本服务的 sequence 恢复扩展与 Claude 官方 SSE不同：官方实时流仅发送连接打开后的事件，恢复建议结合历史列表与事件 ID 去重；不要将本服务的历史回放能力假定为官方语义。

REST 成功响应直接返回该对象；列表的 data 数组元素使用同一对象。是否省略/null 按本表定义。

资源标识。示例："sesn_example"。
type string · 必返
类型标识。示例："session"。

固定的 Agent 快照。创建时固定的完整 Agent 快照；内部字段保持 snake_case。允许 null。示例：{"id":"agent_example","type":"agent","version":1,"model":{"id":"example-model"}}。
environment_id string · 必返
环境 ID。示例："env_example"。
metadata object · 必返
业务元数据。字典值类型为 string。示例：{}。
status string · 必返
状态。rescheduling、running、idle、terminated；requires_action 属于 stop_reason，不是 Session.status。示例："idle"。
title string · 必返
会话标题。允许 null。示例："文档问答"。
created_at string · 必返
创建时间。UTC RFC3339 时间。示例："2026-10-12T08:00:00Z"。
updated_at string · 必返
最后更新时间。UTC RFC3339 时间。示例："2026-10-12T08:00:00Z"。
archived_at string · 必返
首次归档时间。UTC RFC3339 时间。允许 null。示例："2026-10-12T08:00:00Z"。
vault_ids string[] · 必返
Vault 引用。仅保存字符串 ID，不读取凭据；完整说明见配置支持边界。示例：[]。
stats object · 必返
统计值。number 字典；当前固定包含 active_seconds（累计活动秒数）、duration_seconds（自创建起经过秒数）。字典值类型为 number。示例：{"active_seconds":0,"duration_seconds":0}。
usage object · 必返
用量。字典值类型为 integer。示例：{}。
budget JSON · 必返
预算配置。对象或 null；仅保存，不执行限额或超限中止；完整说明见配置支持边界。示例：null。
deployment_id string · 必返
部署引用。允许 null。示例："example"。
runtime_type string · 必返
模型工作池类型。允许 null。示例："agentkit_runtime"。
credential_keys object[] · 必返Identity 凭据引用。子字段在本表下方逐项列出。
Name string · 必返
Identity key 名称。普通引用去空白后非空；MCP 引用必须匹配 [A-Za-z0-9][A-Za-z0-9_-]{0,127}。示例："example-key"。
PoolName string · 必返
Identity pool 名称。普通引用去空白后非空；MCP 引用必须匹配 [A-Za-z0-9][A-Za-z0-9_-]{0,127}。示例："example-pool"。
MCPServerName string · 可能省略
MCP 服务器名称。MCP 引用必填，必须匹配会话 mcp_servers。示例："example-mcp"。可能省略。
HeaderName string · 可能省略
MCP 凭据头。默认 Authorization；合法 HTTP header token，禁止 Host、Cookie、proxy- 前缀。示例："Authorization"。可能省略。
Prefix string · 可能省略
凭据前缀。省略默认 Bearer 加空格；最长 32 字节，禁止 CR、LF、NUL。示例："Bearer "。
resources JSON[] · 必返
资源声明。TOS 存储挂载已移除，不再挂载 /mnt/session/storage/；OpenViking Context 记忆绑定按创建时快照返回，access=read_only 只召回，access=read_write 由 agent-loop 自动保存；不创建 Context、不保存密钥、不代理 Memory CRUD；其他类型只保存；完整说明见配置支持边界。示例：[]。
output_persistence_status string · 可能省略
输出持久化状态。not_required、configured、pending、failed、succeeded。示例："configured"。可能省略。
output_persistence_error_code string · 可能省略
输出持久化错误码。仅失败时返回稳定错误码，不包含上游正文。示例："provider_delete_failed"。
outcome_evaluations JSON[] · 必返
评估结果。示例：[]。
provisioning_status string · 可能省略
工具准备进度。pending、installing、ready、failed；仅存在可报告的工具 Work 时在 Create/Get 中返回。示例："pending"。
operation_id string · 可能省略
异步操作 ID。示例："op_example"。可能省略。
agent_loop string · 必返
Session 固定的执行实现。只返回 adk、codex、dsh、piagent；从创建时冻结的 Agent 快照派生。历史 Session 缺少有效选择时返回 adk。创建后不可更换。示例："codex"。
runtime_id string · 可能省略
物理 AgentKit Runtime ID。返回 Session 固定的 Runtime ID；没有物理 Runtime 绑定时省略。示例："r-example"。

content JSON · 可能省略
内容。按原事件类型保留原始 JSON。允许 null。示例：[{"type":"text","text":"请介绍项目。"}]。可能省略。

tool_use_id string · 可选
工具调用关联 ID。工具结果按协议关联原调用。示例："toolu_example"。
is_error boolean · 可选
工具结果是否错误。示例：false。

DELETE /v1/sessions/{session_id}​

删除托管会话 · DeleteAgentSession

请求参数​

路径参数

session_id string · 必填
session_id 字段。必填；同账号、同授权范围的资源标识。示例："sesn_example"。

查询参数

workspace_id string · 可选
WorkspaceId 字段。示例："example"。

请求体留空。

请求示例​

DELETE /v1/sessions/sesn_example HTTP/1.1

响应参数​

成功返回 HTTP 200。

id string · 必返
资源标识。示例："example_id"。
type string · 必返
类型标识。固定 session_deleted。示例："session_deleted"。

响应示例​

{
  "id": "sesn_example",
  "type": "session_deleted"
}

使用说明​

  • 先持久化删除意图并终态化 Work。
  • 有输出配置时最多等待 30 秒，Provider 删除成功且 Session 记录已删除才返回 HTTP 200 session_deleted；没有输出配置时仍可在清理完成前返回受理成功。
  • 有输出配置但无活动 Dispatch 时直接标记 succeeded。
  • Provider 删除失败返回 HTTP 409，超时返回 HTTP 503；内部错误为 output_persistence_failed/pending，但当前 Service 转换为 Action Conflict/ServiceUnavailable 或 REST reason Conflict/Service_unavailable，原机器码尚未透出。
  • 保留 Session ID 供清理重试，已物理删除后重试返回 404，不是成功结果重放。
  • Provider 删除成功不等于已核验 TOS flush 或对象落盘。
  • workspace_id 可增加范围校验；用户 Bucket 对象不随 Session 删除，不回收共享 Harness、Environment 或模板。

错误体字段见错误响应。

是否还有事件。当前查询范围内还有下一页时为 true；不是本轮运行状态。示例：false。
next_page string · 必返
下一页游标。有下一页时为末条事件的十进制 sequence 字符串；无下一页为 null。示例：null。

GET /v1/sessions/{session_id}/events/stream​

订阅事件流 · SessionEventsStream

请求参数​

路径参数

session_id string · 必填
会话 ID。同账号会话。示例："sesn_example"。

查询参数

after_sequence integer · 可选 · 默认值 Last-Event-ID无有效值则 0
AfterSequence 字段。正数优先；省略或显式 0 回退 Last-Event-ID；两者均无有效值从 0 开始。恢复与历史回放规则见SSE。示例：0。
event_deltas[] string[] · 可选 · 默认值 不返回预览增量
EventDeltas 字段。重复查询参数，最多 100 项；每项只能 agent.message 或 agent.thinking；前者支持文本增量，后者仅开始事件。示例：["agent.message"]。

请求头

Last-Event-ID string · 可选 · 默认值 0
LastEventId 字段。十进制序号字符串；正的 after_sequence 优先，否则读取此请求头。无有效值从 0 开始。示例："1"。

请求体留空。

请求示例​

GET /v1/sessions/sesn_example/events/stream HTTP/1.1
Accept: text/event-stream

响应参数​

成功返回 HTTP 200。

响应类型为 text/event-stream。id 是持久化事件序号，event 是事件类型，data 为事件 JSON；预览没有 id。重连规则见事件流。

持久化事件字段​

以下字段位于每帧的 data JSON 中。

data.id string · 必返
持久化事件 ID。字符串标识。示例："event_example"。
data.type string · 必返
事件类型。只允许：agent.custom_tool_use、agent.mcp_tool_use、agent.mcp_tool_result、agent.message、agent.thinking、agent.tool_result、agent.tool_use、session.error、session.outcome_evaluation、session.status_idle、session.status_rescheduled、session.status_running、session.status_terminated、span.model_request_start、span.model_request_end、user.custom_tool_result、user.define_outcome、user.interrupt、user.message、user.tool_confirmation、user.tool_result；持久化事件不包含 _chunk、stream、event_start 或 event_delta。示例："user.message"。
data.sequence integer · 必返
持久化序号。Session 内单调递增；用于分页和 SSE 恢复。示例：1。
data.created_at string · 必返
创建时间。UTC RFC3339 时间。示例："2026-10-12T08:00:00Z"。
data.content JSON · 可能省略
内容。按原事件类型保留原始 JSON。允许 null。示例：[{"type":"text","text":"请介绍项目。"}]。可能省略。
data.seq integer · 必返
序号兼容字段。与 sequence 相同。示例：1。
data.processed_at string · 必返
服务处理时间。事件受理并规范化时由服务写入 UTC RFC3339 时间；不是模型处理完成标志，也不按该字段排序。示例："2026-10-12T08:00:00Z"。

响应示例​

id: 1
event: user.message
data: {"id":"event_example","type":"user.message","content":[{"type":"text","text":"请介绍项目。"}],"sequence":1,"seq":1,"created_at":"2026-10-12T08:00:00Z","processed_at":"2026-10-12T08:00:00Z"}

使用说明​

预览帧沿用执行器事件格式；持久化事件结构与预览事件不能混用。

  • 持久化事件按 sequence 回放并继续订阅，预览不持久化且不带 id。
  • after_sequence 与 Last-Event-ID 优先级、心跳、5 分钟关闭和重连规则见事件与 SSE。
  • 断流不表示本轮完成。

错误体字段见错误响应。
