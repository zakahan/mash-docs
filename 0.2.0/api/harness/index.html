Agentkit:Harness 管理接口

本页描述与 Runtime 配套的接口契约。目标环境的接口可用性取决于控制面版本。

在 Runtime 使用流程中选择接口​

使用场景控制面接口结果怎么用
定义 Harness AgentCreateHarness、GetHarness、ListHarnesses保存 Harness ID，确认模型、指令、工具、Skills、MCP 与资源配置。字段和示例见下文。
发布配置修订UpdateHarness、ListHarnessVersions更新产生新修订。创建 Managed Session 时，可按 ID 取当前修订，或显式指定版本；已有 Session 使用原快照。
停止后续使用ArchiveHarness、DeleteHarness根据下文的归档和删除语义处理。应用要清理单个对话时，应调用所属组件的 Session 接口。
为托管会话准备环境CreateEnvironment、GetEnvironment、ListEnvironments取得可访问的 EnvironmentId，配置为 Harness 默认环境或在创建托管会话时指定。
为托管会话绑定长期记忆CreateMemoryStore、GetMemoryStore、ListMemoryStores在 Session 的 resources 中引用已有存储 ID；服务校验后冻结绑定信息供执行器消费。
按部署触发托管运行CreateDeployment、RunDeployment、GetDeploymentRun需要部署级运行时绑定时，用 HarnessId 和选定修订创建 Deployment；触发后按运行 ID 查询。

直接调用 Harness App 时，用户、会话和运行接口属于 Runtime HTTP 服务。使用 Worker 的应用则通过托管 Session 数据面读写事件。两种入口分别见 Harness App 调用接口 和 Managed Agents API。上表关联资源的可用状态以对应 AgentKit 契约及目标环境为准。

接口的请求参数、嵌套字段和响应示例均在本页列出。认证方式见调用约定。

统一响应中的 ResponseMetadata 复用公共字段定义，本页只展开各接口的业务结果。

接口分面功能
CreateHarness控制面创建 Harness
GetHarness控制面查询 Harness
ListHarnesses控制面列出 Harness
UpdateHarness控制面更新 Harness
ArchiveHarness控制面归档 Harness
DeleteHarness控制面删除 Harness
ListHarnessVersions控制面列出 Harness 历史版本

控制面固定字段使用 PascalCase，分页使用 MaxResults/NextToken。控制面协议适配已实现，已完成本地 HTTP 契约检查和独立数据库 schema 的幂等回归；线上发布和云端端到端行为尚未验证，示例不能作为线上已支持的证据。

版本、归档与 Session​

创建后的 HarnessVersion 为 1。每次成功更新都会生成下一版本，包括空补丁和相同值赋值；可传当前版本号防止并发覆盖。HarnessVersion>0 获取该历史版本，省略或非正数获取当前对象。已有 Session 使用创建时固定的 Harness 快照，后续更新不会改变它。

Status 为 Active 或 Archived；合法转换为 Active → Archived，Archived 为终态。ArchivedAt 保留首次归档时间；Get/List 当前对象返回当前状态，指定历史版本返回快照当时的状态。归档不增加版本，重复归档保留首次时间；已归档对象可查询，但不能更新或用于创建新 Session。归档不会删除已有 Session。历史版本保存当时的字段值，归档当前对象不会回写历史版本。

Harness 不提供取消归档。DeleteHarness 软删除当前对象并隐藏版本入口，但保留版本快照和既有 Session 固定的 Harness 快照。

分页​

对象列表按 ID 降序，版本列表按版本号降序。MaxResults 默认 100，0 也按 100；有效范围 1～100，负数、超过 100 或非整数返回 HTTP 400。首屏省略 NextToken，后续将 NextToken 原样传入；末页 NextToken=null，空结果 Items=[]，不返回 PrevPage。NextToken 是不透明字符串，不能与其他接口的游标混用。

无效 Base64、空解码值、非法 UTF-8 或带首尾空白的游标内容返回 400；版本列表游标内容必须为规范的正整数版本号。查询不存在或其他账号的对象版本列表时，若没有匹配快照，返回空列表。

HTTP 状态Action 错误码条件与处理

公开 Error.Code 使用点分 PascalCase：每段以大写字母开头，只包含英文字母和数字；无主题时允许单段类别。不返回 Err 前缀、下划线或内部 Proto reason。参数分段使用公开字段名，分页统一为 MaxResults/NextToken；内部错误在 HTTP 输出边界转换，数据面保留原协议。

错误体位于 ResponseMetadata.Error，失败无 Result。创建、更新、归档和删除支持可选 ClientToken，遵循 24 小时账号/Action 隔离重放；同令牌不同参数返回 409 IdempotentParameterMismatch，执行中返回 OperationInProgress，过期返回 ClientTokenExpired，结果不确定返回 409/503 IdempotencyResultUncertain。先查询对象或联系支持，不得换令牌盲目重试。

支持边界​

本页仅描述控制面 Harness 管理 Action，版本为 2025-10-30。数据面 Session 使用创建时固定的 Harness 快照，字段和认证按Session API处理。

Harness 更新生成新版本，Session 更新只改变会话允许修改的字段。模型和工具 JSON 的执行能力由运行环境决定；本服务不承诺完整兼容外部 SDK，详见SDK 接口边界。

控制面已接受 MultiAgent 字段并按 Harness 版本固定配置。多 Agent 已完成本地真实模型的一层委派验证，但尚未完成共享环境部署与线上发布验证。线程执行和结果回传见子 Agent 与线程；配置保存不代表目标运行环境已支持多 Agent 执行。

Tools、Skills 与 McpServers 元素详情​

本节说明 CreateHarness、UpdateHarness 请求及 Harness 响应中 Tools、Skills、McpServers 的元素结构。请求字段表只描述数组层级的约束，元素结构以本节为准。

本节只描述参数契约。线上发布、真实网关调用和端到端执行均未验证；字段被接受或回显不代表执行器已按该配置执行，权限策略、工具启用状态和技能加载的实际效果由运行环境决定。

键名规则​

  • 顶层字段名须为 Tools、Skills、McpServers。元素内及嵌套对象的结构键接受 PascalCase、lowerCamel、snake_case 及混用，服务端转发前递归转为 snake_case：Type、SkillId、McpServerName、DefaultConfig、PermissionPolicy、AllowedDomains、InputSchema 分别落到 type、skill_id、mcp_server_name、default_config、permission_policy、allowed_domains、input_schema；mcpServerName 与 mcp_server_name 同样落到 mcp_server_name。
  • 响应键按现有规则转回 PascalCase；字符串值（工具名、类型取值、域名等）不改写。
  • 同一对象中归一后重名的键一律返回 400 InvalidParameter.<字段路径>，即使值相同也拒绝。例如 McpServerName 和 mcp_server_name 同时出现返回 InvalidParameter.Tools.McpServerName；DefaultConfig.PermissionPolicy 中的 Type 和 type 同时出现返回 InvalidParameter.Tools.DefaultConfig.PermissionPolicy.Type。错误路径使用 PascalCase，不含数组下标；不能用于公开错误码的属性名（如含连字符）省略该路径段，返回可表示的父路径。不同数组元素中的同名字段不冲突。
  • Tools[].InputSchema 的值整体原样透传：外层 InputSchema、inputSchema、input_schema 归一为 input_schema，响应外层键为 InputSchema；值中的所有键和值保持原样，包括 properties/Properties 下的属性名、required/Required、嵌套 schema、$defs 和 $ref。例如 TicketId 保持 TicketId，不会变成 ticket_id。服务端不会把 schema 内的 Type、Properties、Required 自动修正为小写，调用方应使用标准 JSON Schema 关键字。InputSchema 内部不做归一冲突检查，TicketId 和 ticket_id 可以作为两个独立属性同时存在；外层同时提供 InputSchema 和 input_schema 仍因重名返回 400 InvalidParameter.Tools.InputSchema。
  • Metadata、Meta、EnvVars、Headers、AdditionalFields、Networking、System 的内部内容沿用原样保留规则，不做归一冲突检查。

Skills 元素​

Skills 元素按 Type 区分：

Type说明
anthropicAnthropic 托管技能，SkillId 为官方技能标识，例如 "xlsx"。
custom自定义技能。SkillId 可传裸技能 ID，如 "skill_example"，也可传 "技能空间ID/技能ID"，如 "ss-example/s-example"。
Type string · 必填
anthropic 或 custom。
SkillId string · 必填
技能标识。
Version string · 见说明 · 默认值 裸技能 ID 省略时使用最新版本
要固定的版本。完整自定义技能 ID 在创建或更新 Harness 时必填，不能传空值或 latest。
  • Skills 最多 20 项。完整 custom 引用要求恰好两段，每段由字母、数字、下划线或连字符组成。REST 和 TOP 共用校验，ID 或版本不合法时返回 400，TOP 错误码分别为 InvalidParameter.Skills.SkillId 和 InvalidParameter.Skills.Version。合法引用按原值保存并回显。
  • 技能空间ID/技能ID 是 Harness 的完整 SkillId。创建 Session 时，斜杠和点号两种完整引用均以当前账号查询技能空间成员关系和指定版本。校验通过后，Session 快照使用 技能空间ID.技能ID，版本保持原值。
  • 裸技能 ID 沿用 Workspace 默认技能空间。裸 ID 的版本在创建 Session 时解析并固定：Version 省略、为空字符串或为 latest 时取当前最新版本 ID，其他取值必须是该账号下存在的版本；解析失败或版本不可用时拒绝创建 Session。固定结果只写入 Session 快照，不回写 Harness。anthropic 及其他取值的引用原样透传，本服务不解析、不校验，也没有 Anthropic 内置技能库。
  • 未配置技能注册中心时，只要 Harness 含 custom 技能引用，创建 Session 返回 503 api_error（Skill registry is not configured.）；custom 引用无法解析返回 400。

PermissionPolicy 只含 Type 一个字段，可省略或传 null，没有默认值：

Type语义
always_allow工具调用自动放行，不需要用户确认。
always_ask工具调用执行前需要用户确认。
auto服务端按工具、入参和会话上下文逐次判断：安全则放行，高风险则拒绝，无法判断时转为询问。

本服务对 Tools 的限制与差异：

  • 只校验数组长度上限 128，且按数组元素个数计算，不展开 Configs。
  • 除上述键名冲突检查外，不按 Type 做判别式校验，也不校验 Configs、DefaultConfig、PermissionPolicy、InputSchema 的子字段；元素按键名规则保存并回显。配置语义由执行侧校验，本仓库不承诺这些配置已生效。
  • 创建 Harness 时不校验 mcp_toolset 是否引用了 McpServers 中的服务，也不要求每个 MCP 服务都被引用。Session 的 agent_with_overrides 路径校验 mcp_toolset.mcp_server_name 必须命中 mcp_servers 中的 name（不校验反向的未引用服务）。
  • McpServers 元素必须是 JSON 对象，非空 Name 不得重复，最多 20 项；元素内禁止 ApiKey、AuthorizationToken、Authorization、Headers 字段，凭据通过 Session 的 credential_keys 引用。
  • 本服务不解析 PermissionPolicy：工具确认（user.tool_confirmation）与自定义工具事件在会话事件白名单内，但策略判断和确认流程由执行器实现，未验证。
  • Session 覆盖路径会识别 read 工具：Harness 含 Skills 时，必须能识别到 read（顶层元素 Name 为 read，或 agent_toolset_20260401 的 Configs 未把 read 置为 Enabled: false），否则返回 400 agent.tools。

网页工具的执行边界​

以下描述 Managed Agents 网页工具的开发中契约；模型与凭据复用行为尚未确认随目标镜像上线，不能仅凭工具配置被接受就认定已生效，也不能将其套用于通用 VeADK 内置网页工具。

  • 配置与覆盖。 在 agent_toolset_20260401 中启用 web_search 或 web_fetch。更新 Harness 的 Tools 会整体替换配置，已有 Session 仍使用固定快照；新 Session 可通过 agent_with_overrides 提供自己的工具配置。
  • 模型与凭据。 搜索复用当前 Session Agent 的模型 ID、有效 Base URL 和 Runner 已解析的模型凭据；协议由 Worker 配置决定，快照中的 provider 不覆盖它。该搜索后端要求 openai 协议和受支持的方舟 HTTPS 入口，不支持任意 OpenAI 兼容地址。云 Session 的 x-ark-key-name 是当前账号下的方舟 API Key Name，不是明文 Key；它也不替代环境访问密钥。
  • URL 来源。 UrlSources 包含 user_input、client_tool_results、server_tool_results，省略或 null 表示 all，也可选 none。工具结果来源支持 type=only 或 type=except 并指定工具名单；三种来源不能全部禁用。抓取 URL 必须已出现在允许来源的持久化 Session 历史中，缺少历史或读取失败时拒绝抓取。
  • 网络限制。 web_fetch 只接受无内嵌凭据的绝对 HTTP(S) URL，拒绝回环、私网、链路本地和云元数据地址。DNS 解析和每次重定向都需要通过网络与域名检查；加入域名白名单不能豁免私网限制。
  • 结果校验。 用 agent.tool_use.id 与 agent.tool_result.tool_use_id 关联调用，检查 is_error 和实际结果。搜索读取 results[].url，抓取读取 content；HTTP 200 或模型声称已搜索均不能代替工具结果。事件读取和恢复见 Session API。

调用示例​

下面的示例创建一个同时配置 Skills、Tools 与 MCP 的 Harness，再按返回的 HarnessId 查询。$HARNESS_BASE_URL 为部署提供的控制面入口；账号签名与认证头由 SDK 或网关按调用约定生成，示例省略这些头，Model.Id 替换为运行环境可访问的模型，不要把 API Key 写入请求。

curl -sS -X POST "$HARNESS_BASE_URL/?Action=CreateHarness&Version=2025-10-30" \
  -H "Content-Type: application/json" \
  -d '{
    "Name": "订单助手",
    "Model": {"Id": "example-model"},
    "McpServers": [
      {"Name": "orders", "Type": "url", "Url": "https://mcp.example.com/orders"}
    ],
    "Tools": [
      {
        "Type": "agent_toolset_20260401",
        "DefaultConfig": {"Enabled": true, "PermissionPolicy": {"Type": "always_ask"}},

错误​

Skills 超过 20 项、Tools 超过 128 项或 McpServers 超过 20 项返回 400。控制面错误使用 TOP 错误信封 ResponseMetadata.Error，错误码为点分 PascalCase，例如 InvalidParameter.Tools、InvalidParameter.Skills、InvalidParameter.McpServers、InvalidParameter.McpServers.Name；请求体不是合法 JSON 对象时见错误响应。

Harness 对象​

元数据。最多 16 对自定义键值，不含系统标签；键最多 64 个 Unicode 字符，值须为字符串且最多 512 个 Unicode 字符。按键合并，null 删除对应键；省略、null 或 {} 保留原值；合并后校验自定义键值总数。示例：{"purpose":"documentation"}。
HarnessVersion integer · 可选 · 默认值 不校验版本
预期版本。提供时必须等于当前版本，否则返回 HTTP 409；建议读取当前 Version 后传入，避免覆盖并发更新。示例：1。
Payload JSON · 可选 · 默认值 保留原值
自定义 JSON 数据。支持对象、数组、字符串、数字、布尔值和 null；对象键名保持原样。传入时整体替换，显式 null 保存为 JSON null。示例：{"RunOptions":["fast",false]}。
EnvironmentId string · 可选 · 默认值 保留原值
默认 Environment ID。传入同账号可访问且未归档的环境 ID，或传空字符串清除。省略保留原值。更新产生新 Harness 版本。示例："env_example"。
RuntimeTemplateId string · 可选 · 默认值 保留原值
默认 RuntimeTemplate ID（即将过期）。即将过期。传入同账号可访问的 Ready 模板 ID 时补全并保存对应 RuntimeId；传空字符串仅清除模板字段，保留已固定的 RuntimeId。省略保留原值。更新产生新 Harness 版本。示例："rt_example"。
ClientToken string · 可选 · 默认值 不启用幂等重放
幂等令牌。非空时为 1～64 个可打印 ASCII 字符（不含空格）。按账号和 Action 隔离；24 小时内同令牌同参数重放首次结果，不重复创建或增加版本。不同参数返回 409 IdempotentParameterMismatch；过期令牌拒绝复用。省略、null 或空字符串保留非幂等行为。示例："harness-request-1"。
