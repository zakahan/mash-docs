# 开发 Managed Agents Worker

应用通过 Session 数据面操作会话。扩展执行行为时，应明确会话快照如何转换为 Agent 配置，以及工作调度、执行和事件交付之间的职责。

| 环节 | 负责的工作 |
|---|---|
| 工作调度 | 领取与调度工作，维护执行租约，处理停止接收新任务的过程。 |
| 配置转换 | 将固定快照中的模型、指令、工具和 MCP 配置转换成 Agent 配置。 |
| 执行循环 | 推进单 Agent 或多 Agent 运行，处理输入与执行结果。 |
| 事件交付 | 记录和交付会话事件，使调用方能够关联输入、工具调用与执行结果。 |

例如扩展一项工具权限时，先检查控制面的 Harness 字段能否描述该权限，再检查 Worker 对固定快照的解析和执行前权限检查。

## 验证要点

- 显式声明新权限的会话按配置执行，未包含新字段的旧快照继续兼容。
- 会话资源和工具配置正确传递到执行过程，资源权限与会话身份一致。
- 网页工具的调用结果与事件能够关联，访问限制和失败处理符合配置。
- 调用方能通过 Session 事件判断完成、失败或等待确认，不能仅凭连接关闭判断执行结果。

请求字段、会话状态与事件格式见 [Managed Agents API](../api/session.md)。
