# 工具、资源与多 Agent

## 工具与技能

Worker 从会话快照读取工具配置、MCP 服务和系统指令。控制面中的工具声明描述模型可用的能力；具体执行还需要匹配的后端与身份。外部工具由客户端完成时，先读取对应的工具请求事件，再使用匹配的调用标识回传结果。接入方可从事件历史关联发起请求、执行与结果。

## 知识和记忆

知识绑定描述 Agent 可检索的材料；会话的 `resources` 可绑定已有的 MemoryStore。下面的条目可加入创建 Session 的 `resources` 数组。服务校验资源归属并生成会话使用的记忆快照。默认只读，计划写入时需显式选择相应的访问模式。

```json
{"type":"memory_store","memory_store_id":"mem_example","access":"read_only"}
```

## 子 Agent 与线程

启用多 Agent 的会话可以配置子 Agent。主线程委派工作后，子线程基于自己的 Agent 快照执行，结果回到父线程。接入方在解释工具事件和任务进度时需要区分线程归属。增加子 Agent 前，应先明确它负责的任务、可用工具以及主线程需要的返回内容。
