对话调用接口

本页记录 0.4.0（待发布）的 Harness App 对话执行、SSE 与 A2A 接口。请求路径相对于已授权的 Runtime 地址。使用 /run、/run_sse 或 /invoke 时，先通过会话管理接口创建会话并保存返回的 id。A2A 消息调用按本页对应接口构造请求。认证方式与请求头取决于 Runtime 部署，具体字段见各接口。沙箱文件的上传、列出与下载见文件操作接口。

POST /run​

运行对话 · RunAgent

在已创建的会话中执行一次 Agent 并在执行完成后返回事件数组，适用于非流式调用。

请求参数​

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>；身份模式下 userId 的有效值由认证主体决定。
X-Session-Id string · Header · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
appName string or null · Body · 可选
应为 harness_agent；省略时由服务端选择应用。
userId string · Body · 必填
用户标识；身份模式下服务端使用认证主体覆盖该值。
sessionId string · Body · 必填
已创建的会话标识。
newMessage Content or null · Body · 可选本轮输入消息。
role string or null · Body · 可选
消息角色，调用方消息通常为 user。
parts Part[] or null · Body · 可选消息分片。
text string or null · Body · 可选
文本内容。
inlineData Blob or null · Body · 可选
内联二进制内容，包含 MIME 类型和 Base64 数据。
fileData FileData or null · Body · 可选
URI 文件内容。
functionCall FunctionCall or null · Body · 可选
函数调用。
functionResponse FunctionResponse or null · Body · 可选
函数调用结果。
executableCode ExecutableCode or null · Body · 可选
可执行代码。
codeExecutionResult CodeExecutionResult or null · Body · 可选
代码执行结果。
thought boolean or null · Body · 可选
是否为思考内容。
thoughtSignature string or null · Body · 可选
Base64 编码的思考签名。
videoMetadata VideoMetadata or null · Body · 可选
视频元数据。
mediaResolution PartMediaResolution or null · Body · 可选
媒体分辨率配置。
toolCall ToolCall or null · Body · 可选
服务端工具调用。
toolResponse ToolResponse or null · Body · 可选
服务端工具调用结果。
partMetadata object or null · Body · 可选
分片自定义元数据。
audioTranscription Transcription or null · Body · 可选
音频转写内容。
streaming boolean · Body · 可选
是否要求模型流式生成；默认 false。

先创建会话。返回完整的 ADK Event 数组，按顺序读取每个事件的 content.parts。

POST /run_sse​

流式运行对话 · RunAgentSSE [推荐]

日常对话调用推荐使用此接口，以便及时接收增量输出；/run 保留用于需要完整事件数组的调用。在已有会话中运行 Harness Agent，以 SSE 返回事件。服务认证部署的绑定会话默认使用固定版本对应的实例快照；缓存缺失或版本不一致时按 Session 中的版本自动重建。普通消息不会仅因经过一段时间而读取最新 Harness。

请求体

harness_version integer · 可选
续聊通常省略；显式提供时必须是正整数且与 Session 固定版本一致，不能用它切换版本。与 refresh_snapshot: true 互斥。
refresh_snapshot boolean · 可选 · 默认值 false
传 true 时，用原绑定获取最新 Harness 和当前 Environment，成功后持久化实际版本、替换快照并执行本轮。字符串和 null 返回 422。
harness object · 可选设置本轮 Harness Agent 使用的模型、指令和工具。
model_name string · 可选
模型名称；绑定会话省略时沿用快照，未绑定时沿用部署配置。
system_prompt string · 可选
系统提示词。
tools string · 可选
逗号分隔的内置工具名称。
skills string · 可选
逗号分隔的 Skill Hub slug、Space ID 或 Space:Skill 引用。
runtime adk or codex · 可选
默认 adk。

最大模型调用次数，最小值为 1。

model_api_key string · 可选
模型 API 密钥。仅用于兼容历史调用方，新调用方应改用 X-Model-API-Key；两者同时提供时以 Header 为准。

响应与错误​

成功建连后以 text/event-stream 逐帧发送 ADK Event。请求级适配器使用 Cache-Control: no-cache。以下仅展示文本相关字段：

data: {"partial":true,"content":{"parts":[{"text":"甲"}]}}

data: {"partial":false,"content":{"parts":[{"text":"甲乙"}]}}

兼容处理器在建连前发现参数错误时返回 HTTP 422；建连后执行失败可返回 data: {"error":"..."} 并结束流。客户端应读完整消息结算预览文本。流式事件消费

注意事项：绑定会话与配置覆盖​

本轮请求App 的处理方式
省略 refresh_snapshot 或传 false使用 Session 固定版本对应的快照。实例内没有匹配缓存时，按 state.harness_version 自动查询历史版本并重建，然后执行本轮；不会升级到最新版本。
传 refresh_snapshot: true用已保存的三个 ID 查询最新 Harness 和当前 Environment，校验成功后先持久化实际版本，再替换快照并执行消息。任一步失败都保留原版本和原快照，本轮在建连前结束。未绑定会话请求刷新返回 409。
显式提供 harness_version仅用于断言版本，必须是正整数并与 Session 固定版本相同。不能切换版本，也不能与 refresh_snapshot: true 同时提供；冲突返回 422。
提供 harness在本轮使用的快照上应用显式字段，省略的字段继承快照。sandbox、knowledgebase 对象按子字段合并，数组整体替换。若同时刷新，先取新快照。请求覆盖只对本轮有效。
覆盖模型地址且快照含密钥若 harness.model_api_base 与快照不同，必须显式提供本轮凭证，优先使用 X-Model-API-Key。即使快照已有密钥，省略本轮凭证也会在建连前返回 422。

在 ADK 直接调用模型的链路上，model_provider 为 openai 或 openai-responses 时使用 Ark Responses，openai-completions 使用 Chat Completions。请求级 harness.model_provider 优先于快照的 Model.Provider。两个创建入口、主动刷新、SSE 和这两种模型协议已经实际验证，工具调用尚未实测。

data: {"jsonrpc":"2.0","id":"rpc-2","result":{"kind":"artifact-update","taskId":"task-2","contextId":"ctx-1","artifact":{"artifactId":"task-2:answer","name":"answer","parts":[{"kind":"text","text":"你好。"}]},"lastChunk":true}}

Harness 流式扩展： status.message.metadata.harness.partial=true 表示模型增量；false 表示完整的非增量文本，不能再追加到已拼接的文字后面。最终以 answer 产物为答案。多次模型调用可能产生多段文字；协议没有额外提供逐段 ADK 消息 ID 的对应契约。首字延迟应取第一个含非空正文的状态消息到达时间，不能拿初始 Task 或 working 空状态帧计时。

错误与支持边界

场景返回与处理
Runtime 认证拒绝在进入处理器前返回 HTTP 错误，按部署认证策略处理。
非 user 消息、空内容、无效 Base64、非法 Harness 覆盖、携带 taskId、blocking=falseJSON-RPC error，参数错误码 -32602；修正请求后再调用。
模型或工具执行链路失败Task 进入 failed，错误消息为 Harness invocation failed；不要将 HTTP 200 当作成功。
tasks/get、tasks/cancel、tasks/resubscribe、推送通知配置等未开放方法JSON-RPC -32601（Method not found）。configuration.pushNotificationConfig 也不支持。
SSE 中收到 error协议调用失败，读取 error.code、error.message；不要当作正文。
SSE 未收到终态就断开本轮结果未知。断连不保证取消执行；没有 Last-Event-ID 续传或任务重订阅，不要盲目重发有副作用的请求。

任务只在当前执行期间使用内存存储，终态后清理；会话上下文与 Task 生命周期不同。不能依赖 Task ID 在重启后查询结果，也不提供业务幂等保证。
