会话管理接口

本页记录 0.4.0（待发布）的 Harness App 会话管理接口。请求路径相对于已授权的 Runtime 地址。示例使用应用名 harness_agent、用户 reader-1 和会话 report-1。认证主体和路径中的用户需满足该入口的身份要求。

请求推荐使用本页列出的驼峰字段。workspaceId、harnessId、harnessVersion、environmentId 和集合创建入口的 sessionId 兼容对应的下划线名称；绑定字段同时提供两种名称时，值或类型不一致返回 422。新建会话不接受 refreshSnapshot: true；该字段兼容 refresh_snapshot。集合创建入口也兼容 file_ids；指定 ID 的创建入口请使用 fileIds。会话绑定和文件声明以驼峰名称保存。

创建会话后，通过对话调用接口发送消息；需要直接操作沙箱中的文件时，使用文件操作接口。

绑定会话与认证​

本版本的两个创建入口都可以用三个顶层 ID 绑定会话。调用方先通过 CreateHarness 取得 Harness ID，再选择同一 Workspace 的 Environment。Runtime 负责认证入站请求。Harness App 使用部署的服务身份调用 agentkit:GetHarness 和 agentkit:GetEnvironment。启用或强制共享身份的部署在创建绑定会话时返回 422。

两个资源都须为 Active，且 Environment 的 Config.Type 为 Cloud、顶层 ToolId 非空。两项查询和配置校验均成功后，App 将三个 ID 和 GetHarness 返回的实际版本随会话 state 保存，将解析出的模型、指令、Skills、MCP 和沙箱配置放入当前实例的内存。快照按应用、用户和会话 ID 区分，创建响应回显绑定 ID、harnessVersion 和会话自身的数据。控制面快照和其中的凭据不会写入会话存储。

创建或刷新时的 HTTP 状态触发条件
403、404、429相应控制面查询被拒、找不到资源或限流。资源返回的 Workspace 与请求不一致也返回 404。
409Harness 或 Environment 未处于 Active。
422绑定字段不合法、使用共享身份、Environment 为 SelfHosted 或缺少 Cloud ToolId，或返回的配置不受支持。
502其他控制面查询失败。

会话标识与响应约定​

X-Session-Id 是 Runtime 返回的可选路由亲和标识；收到后原样回传。同一业务对话仍需保存创建响应正文中的 id，用作路径或请求体的会话标识。JSON 请求发送 Content-Type: application/json；流式调用可声明 Accept: text/event-stream。示例只列与各操作相关的字段，认证头见各接口表。

绑定 Harness 中的自定义 Skill 按空间和 Skill ID 加载最新可用版本；Skills[].Version 不固定 Harness App 的执行版本。Skill 加载与缓存

GET /apps/{appName}/users/{userId}/sessions​

查询会话列表 · ListSessions

查询指定用户在 Harness App 下的全部会话，用于展示会话列表。

请求参数

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>；具体 token 类型由 Runtime 的认证模式决定。
X-Session-Id string · Header · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
appName string · Path · 必填
应为 harness_agent。
userId string · Path · 必填
会话所属用户标识。

调用示例

GET /apps/harness_agent/users/reader-1/sessions

响应字段

X-Session-Id string · Header · 可能省略
Runtime 分配的会话亲和标识；后续请求应原样回传。
[] Session[] · Body · 必返会话数组；没有会话时返回空数组。
id string · Body · 必返
会话标识。
appName string · Body · 必返
应用名。
userId string · Body · 必返
会话所属用户标识。
status string · Body · 必返
Runtime 维护的真实会话运行状态，不从 events 推断。枚举：idle（空闲或正常完成）、running（正在执行）、waiting（等待认证、确认、异步结果或未闭合工具调用）、error（执行失败）。
title string · Body · 必返
会话标题。首次收到非空用户文本时，Runtime 在本地取第一句话生成，最长 40 个字符，且不调用模型（额外模型 Token 消耗为 0）；后续消息不自动覆盖。尚未生成标题的会话返回 新会话。

workspaceId string · Body · 可能省略
绑定会话使用的 Workspace；旧会话或未绑定会话可缺省。
harnessId string · Body · 可能省略
绑定会话使用的 Harness；旧会话或未绑定会话可缺省。
harnessVersion integer · Body · 可能省略
Session 固定的 Harness 版本；绑定会话存在，旧会话或未绑定会话可缺省。
environmentId string · Body · 可能省略
绑定会话使用的 Environment；旧会话或未绑定会话可缺省。
fileIds string[] · Body · 可能省略
创建时声明的文件 ID；旧会话可缺省。
{key} any · Body · 可能省略
业务自定义状态项。
events Event[] · Body · 必返
按发生顺序保存的会话事件；可为空数组。
lastUpdateTime number · Body · 必返
最近更新时间，Unix 秒时间戳；未发生更新时可为 0。

空列表返回 HTTP 200 和 []。已有会话时返回下文 GetSession 对象组成的数组。恢复历史请读取会话详情；列表返回的事件数量取决于会话后端。

source string · Body · 可选
Skill 来源；外部公开 Skill 包使用 public_url。省略时按 public_url 处理。
url string · Body · 必填
外部公开 Skill zip 下载链接，必须是 HTTPS URL；不要求 URL path 以 .zip 结尾，Runtime 按响应内容校验 zip 包。
resources object[]、JSON 数组字符串或 null · Body · 可选
兼容字段。skills 为空时选用非空的 resources，两者均为空时绑定会话使用快照中的 Skills。

请求参数

Authorization string · Header · 必填
认证凭证，格式为 Bearer <token>；具体 token 类型由 Runtime 的认证模式决定。
X-Session-Id string · Header · 可选
Runtime 返回过该值时原样回传，用于维持会话亲和性。
appName string · Path · 必填
应为 harness_agent。
userId string · Path · 必填
会话所属用户标识。
sessionId string · Path · 必填
会话标识。

调用示例

DELETE /apps/harness_agent/users/reader-1/sessions/report-1

响应字段

— — · Body · 可能省略
成功时无业务响应字段。

成功时没有业务返回对象。删除后再查询详情将返回 404。
